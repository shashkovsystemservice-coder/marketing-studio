# Постановка задачи: тест маркетинговых способностей

**Цель:** создать диагностический инструмент, оценивающий способности организации в маркетинге по 13 территориям канонической онтологии RC3.

## Разделение уровней
1. **Онтология:** территория → подгруппа → элемент, плюс структурные отношения между элементами.
2. **Измеряемый конструкт:** что именно является способностью организации применительно к элементу (знание, практика, процесс, ресурс, доказательство, результат). Не каждый элемент сам по себе измерим.
3. **Вопрос:** закрытый single-select, да/нет/не знаю, шкала или множественный выбор; обязательна возможность указать неопределённость.
4. **Ответ:** типизированное утверждение, привязанное к объектам, источнику, контексту и времени.
5. **Интерпретация:** прямое измерение, косвенный сигнал или необходимость проверки — отдельно.
6. **Профиль:** агрегирование на уровне подгрупп и 13 территорий лишь после проверки методики.

## Принцип связности
Один ответ может относиться к нескольким объектам и запускать последующие проверки по отношениям RC3. Связь не доказывает способность и не даёт права автоматически повышать соседние оценки.

## Ограничения
- RC3 является концептуальной онтологией, не готовым психометрическим тестом.
- 185 элементов не равны 185 обязательным вопросам.
- Не вводить произвольные веса и шкалы без обоснования.
- MASTER — вторичный источник для профессиональной интерпретации и следующих действий.

## Первый рабочий результат
Матрица: RC3 element ID → диагностируемая характеристика → вопрос ID → затрагиваемые relation ID → тип свидетельства → правило оценки → необходимость проверки.

**Статус:** проект методологии, требует проверки на кейсах.
