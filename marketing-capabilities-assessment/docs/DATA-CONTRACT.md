# Контракт данных RC3

Источник: каноническая таблица RC3 BLOCK1 COMPLETE (Google Drive). Импорт сделан без изменения исходного файла.

## rc3-elements.json
185 объектов с неизменёнными локальными ID. Содержит территорию, подгруппу, имя, тип, определение, критерий идентичности, контекст и дополнительные поля типизации RC3.

## rc3-relations.json
50 принятых отношений. Поля domain/range сохранены **как исходные выражения**, включая диапазоны и внешние идентификаторы. Нельзя трактовать строку `T2.06–T2.16` как один ID и нельзя автоматически раскрывать диапазон без отдельного проверенного парсера.

## Границы интерпретации
- Структурная связь — не причинность и не правило оценки.
- Данные ответов и оценок будут отдельными сущностями, не частью канонического реестра.
- Каждый вывод должен иметь источник, контекст, время и уровень уверенности.
- Правила покрытия, веса и диагностические вопросы находятся в разработке.

## Контроль качества
Счётчики: 13 территорий, 185 уникальных ID элементов, 50 уникальных ID отношений. Проверить определения, типы, ссылки на внешние объекты и применимость каждой связи до реализации логики распространения.
