# RC3 — научно-трассируемый диагностический каркас 13 земель v0.2

**Статус:** исследовательский проект, НЕ валидированный опросник. Земли и элементы взяты из реального канонического `data/rc3-elements.json` (185 элементов). Краткие названия земель — рабочие ярлыки, не официальные заголовки. Каждый вопрос ниже — **авторская формулировка**, не цитата из опубликованной шкалы.

## Научная рамка

- Vorhies & Morgan (2005): организационные маркетинговые способности измеримы самоотчётами; оригинальный инструмент — сравнительная шкала, не прямой источник вопросов ниже.
- Hinkin (1995): разработка организационных шкал требует определения конструкта, анализа пунктов, проверки надёжности и валидности.
- Исследования cognitive interviewing (2007, 2022): перед запуском нужно проверить, как неспециалисты понимают вопросы.
- Исследования маркетинговых способностей МСП (2023): применимость самоотчётных исследований к МСП; не валидация нашего теста.

## Протокол интерпретации (без псевдоточности)

1. Первый ответ: практикует / частично / не практикует / не знает / не применимо. Вопросы с иной семантикой требуют своих вариантов, нельзя навязывать одну шкалу.
2. Уточнения выбираются по смыслу: последний случай, решение после информации, применимость, кто знает ответ. **Не** требовать документов.
3. Наличие действия, регулярность, влияние на решения, осведомлённость и уверенность — разные переменные. Частота и формализация не автоматически повышают оценку.
4. Пример — дополнительный самоотчёт, а не независимая проверка. Несогласованность — повод уточнить контекст.
5. До эмпирической калибровки не вычислять точный балл по 13 осям и не объявлять результаты объективными.

## Дальнейшая работа

- Проверить содержание каждого кандидата против всех элементов соответствующей земли, а не считать один пункт полным покрытием.
- Расширить каждую землю до нескольких действительно различимых способностей, где это оправдано RC3 и литературой.
- Создать таблицу происхождения каждого вопроса: `RC3 ID → конструкт → научный источник (уровень поддержки) → авторская операционализация → вопрос → шкала → условие уточнения → статус валидации`.
- Когнитивные интервью с владельцами и сотрудниками МСП; затем пилот с проверкой устойчивости и пропусков.
