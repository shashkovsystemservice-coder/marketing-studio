# Marketing Capabilities Assessment

Самостоятельный исследовательский прототип теста маркетинговых способностей компании. Разработка ведётся в изолированной ветке; ветка main и действующий сайт не меняются.

## Методологический фундамент
- Первичный источник: RC3 — 13 территорий, 185 элементов и 50 принятых структурных отношений.
- MASTER применяется как вспомогательная методология интерпретации, не как структура теста.
- Ответ привязывается к объектам RC3 и может порождать проверки по отношениям.
- Перенос факта по связи **не означает** автоматический перенос оценки.
- Вопросы, шкалы и веса пока не валидированы; числовая оценка не должна выдаваться за измеренную способность.

## Следующий этап
1. Импортировать все 185 элементов с идентификаторами, типами и определениями.
2. Импортировать 50 отношений с domain, range, направлением и ограничениями.
3. Построить матрицу диагностического покрытия.
4. Проектировать типизированные вопросы и повторное использование ответов.
5. Разработать и проверить модель агрегации 13 показателей.

Текущая ветка — рабочая, не утверждённый продукт.
